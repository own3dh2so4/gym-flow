# Gym Flow

## Project

Gym Flow is a Spanish, mobile-first fitness PWA. It uses Next.js App Router, TypeScript, and local browser storage. There is no account or backend.

## Development

- Use `npm run dev` for local development.
- Use `npm run typecheck` before submitting changes.
- Use `npm run build` to verify a production build.
- Keep the interface copy in Spanish.
- Keep code, docs, and comments in English.
- Keep workout data typed and deterministic in `src/data`.
- Keep personal data on-device; do not add analytics or external tracking without explicit approval.

## Product principles

- Prioritize thumb-friendly interactions and accessible contrast.
- Never present exercise guidance as medical advice.
- Every exercise needs a clear technique description and a substitution.
- Prefer small, composable components over large page components.
